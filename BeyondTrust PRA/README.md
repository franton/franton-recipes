## BeyondTrust PRA

To be honest, I recommend people use this https://richard-purves.com/2022/05/15/downloading-beyondtrust-remote-support-via-api-for-fun-and-profit/ instead of this recipe.

However there are times when admins will not let you mess with their APIs so this exists as the backup.

Make an override of the pkg recipe, customise the internal variables and place a pre-downloaded PRA install DMG into the folder to generate the pkg.

I recommend only running this as required or you'll get fail errors.
